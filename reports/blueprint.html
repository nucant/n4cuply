A1

Brief & rules

Ki chai

  • Nijer banano gaan phone ar PC-te shona
  • Spotify-r moto shundor player
  • Ekhon gaan Google Drive-e, pore pCloud-e
  • Project GitHub-e, kintu keu gaan access korte parbe na

Design rules

  • Kono server nei, kono database nei
  • App = shudhu HTML, CSS, JavaScript
  • Tala (lock) = Google login (pore pCloud login)
  • Gaan Drive theke sorasori device-e ashe
  • Drive ar pCloud dutoi plug-in, setting bodlalei switch

Ja kokhono hobe na

  • Gaan GitHub-e upload
  • Password ba secret code-e likha
  • Drive folder "Anyone with link" public kora
  • Tomar Google password amar kache jawa
A2

Folder link dile hobe na keno?

Shudhu folder link

Folder private thakle Google kauke dhukte dey na, amar app-keo na. Link diye cholate hole folder-ta "Anyone with the link" korte hobe. Tokhon je keu link pele tomar sob gaan shunte parbe.

Client ID diye

Folder private-i thake. App khulle Google login ashe, tumi login korle tobei gaan dekha jay. Client ID holo app-er porichoy-potro, Google-ke bole "ei app ta tomar". Eta secret na, code-e thakleo kono khoti nei.

Client ID tomar nijer Google account theke banano, tai control-o tomar hate. Jokhon khushi Google Cloud theke bondho kore dite paro.

D3

Audio technical info

File-er header theke, tag na thakleo pawa jay

Sob format

  • Codec + container (FLAC, MP3, AAC, ALAC, Opus, Vorbis, PCM)
  • Lossless / lossy badge
  • Sample rate (44.1 / 48 / 96 / 192 kHz)
  • Bit depth (16 / 24 / 32-bit)
  • Channels + mode (stereo, joint stereo, mono, 5.1)
  • Bitrate: asol average = size × 8 ÷ duration
  • Exact duration, total samples
  • Hi-Res badge: 24-bit ba 44.1 kHz-er beshi hole

FLAC

  • STREAMINFO: min / max block size, frame size
  • Audio MD5 signature
  • Encoder vendor (jemon reference libFLAC 1.4.3)
  • Embedded picture: type, mime, px, KB
  • Compression ratio (FLAC size ÷ WAV size)

MP3

  • MPEG version + layer (MPEG-1 Layer III)
  • CBR / VBR / ABR (Xing, Info, VBRI header theke)
  • LAME tag: encoder version, preset (jemon -V0, 320 CBR), lowpass
  • ID3 version (v2.3 / v2.4 / v1)
  • Emphasis, CRC, copyright / original flag

M4A / WAV / OGG

  • M4A: AAC-LC / HE-AAC / ALAC, encoder (iTunes ityadi)
  • WAV: PCM / float, bit depth, LIST INFO tag
  • OGG / Opus: vendor, pre-skip, output gain

File

  • File naam, size (MB), extension
  • Drive-e kon folder, kobe upload / modify
  • Tag size, artwork size alada

Analysis (play korar somoy)

  • Waveform seek bar
  • Live spectrum analyzer + peak / VU meter
  • Spectrogram + lossless check: 16 kHz-e cut thakle "MP3 theke banano FLAC hote pare" warning
  • Peak dBFS, approx LUFS, DR (dynamic range)
D4

Info kivabe asbe

Puro gaan download na kore
  1. STEP 1Folder scanAger motoi file list
  2. STEP 2Header readProttek file-er shudhu shurur ~256 KB (M4A hole seshe-o)
  3. STEP 3ParseNijer parser: ID3, FLAC, MP4, OGG, WAV. Kono 3rd party library na
  4. STEP 4Device-e saveIndexedDB-te. Porer bar file bodlale tobei abar pora
  5. STEP 5LibraryTag onujayi artist, album, genre, year

Prothom bar scan-e ektu somoy lagbe (100 gaan ≈ kichu second), library pichone update hote thakbe. Waveform ar spectrogram-er jonno puro gaan decode korte hoy, tai eta shudhu je gaan cholche tar jonno.
