A1

Brief & rules

Ki chai

  • Nijer banano gaan phone ar PC-te shona
  • Spotify-r moto shundor player
  • Ekhon gaan Google Drive-e, pore pCloud-e
  • Project GitHub-e, kintu keu gaan access korte parbe na

Design rules

  • Kono server nei, kono database nei
  • App = shudhu HTML, CSS, JavaScript
  • Tala (lock) = Google login (pore pCloud login)
  • Gaan Drive theke sorasori device-e ashe
  • Drive ar pCloud dutoi plug-in, setting bodlalei switch

Ja kokhono hobe na

  • Gaan GitHub-e upload
  • Password ba secret code-e likha
  • Drive folder "Anyone with link" public kora
  • Tomar Google password amar kache jawa
A2

Folder link dile hobe na keno?

Shudhu folder link

Folder private thakle Google kauke dhukte dey na, amar app-keo na. Link diye cholate hole folder-ta "Anyone with the link" korte hobe. Tokhon je keu link pele tomar sob gaan shunte parbe.

Client ID diye

Folder private-i thake. App khulle Google login ashe, tumi login korle tobei gaan dekha jay. Client ID holo app-er porichoy-potro, Google-ke bole "ei app ta tomar". Eta secret na, code-e thakleo kono khoti nei.

Client ID tomar nijer Google account theke banano, tai control-o tomar hate. Jokhon khushi Google Cloud theke bondho kore dite paro.

A7

Features

Version 1

  • Google login / logout
  • Library: folder = album, sub-folder support
  • Play, pause, next, previous, seek bar
  • Shuffle, repeat, queue
  • Search (gaan ba album-er naam)
  • Full-screen "Now Playing" + mini player
  • Lock screen ar headphone control
  • Phone-e app hisebe install (PWA)
  • Dark, Spotify-style design

Pore jog kora jabe

  • pCloud source, approve hole
  • Album art: folder-e cover.jpg rakhlei
  • Playlist
  • Lyrics: gaaner pashe .lrc file
  • Favourite gaan offline-e save
